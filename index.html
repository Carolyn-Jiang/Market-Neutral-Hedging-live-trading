04 / TEST PROTOCOL

How the rounds work

1. Release and decide

Round 1 at 14 October 09:30 publishes data only. Releases 2–12 on 14–15 October launch both data collection/publication and settlement of the preceding round.

Releases occur at 09:30, 10:30, 11:30, 12:30, 14:30, and 15:30 each day. Intraday action deadlines are five minutes before the next release.

2. Settle consistently

At each subsequent event, evaluate the previous accepted pair action using the fixed valuation and scoring rules. Missing valid actions are scored as F. Compound completed-round returns.

The 14 October 15:30 action is due on 15 October at 09:25. The final action is due on 16 October at 08:00.

3. Seal the baseline

Codex chooses two stocks and LS, SL, or F from each round’s available data. Its decision is recorded privately before the following release, then scored with the same rules as every team.

Neither team actions nor baseline decisions are disclosed on the live board.

4. Finish the test

16 October 09:30 runs settlement only, using internal terminal prices. There is no thirteenth participant data release.

At 10:00, publish final rankings and cumulative-return curves after terminal settlement completes. The Codex baseline is a reference, not a competing team.

This is a competition simulation, not a brokerage execution service. Position sizing, valuation, execution timing, and transaction costs must be fixed in the verified scorer before trading opens.
